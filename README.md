# 普惠法律智能体 · 架构调研与落地蓝图

> 面向现代人法律意识淡薄、法律服务门槛高的问题，对一个「AI 普惠法律入口 + 真人律师合规变现」的法律智能体进行系统性架构调研与落地规划。

## 项目背景

律师咨询通常 200–800 元/小时起，小额维权的成本常接近标的本身，大量普通人在咨询阶段就放弃维权。与此同时，2024 年全国法院受理案件约 4601.8 万件，消费投诉超 1862 万件，高频集中在借贷、买卖、离婚、交通事故、劳动争议等场景。

本项目调研了一个法律智能体「应该怎么做、能不能做、如何低成本做、未来如何演进」，形成可直接指导产品开发、参赛申报与融资的完整决策报告。

## 核心结论

- **总打法**：AI 做免费普惠入口 + 真人律师做合规变现；不自研基座模型，胜负手在法律数据深度、场景闭环与合规信任。
- **技术路线**：开源底座法律后训练 + 强工程化 RAG + LangGraph 多 Agent（前台接待 / 法律分析 / 类案检索 / 文书起草 / 合同审查 / 合规审核）。
- **数据策略**：免费官方库（国家法律法规数据库、人民法院案例库等）+ 商业授权 + 开源数据三层组合，不依赖批量爬取裁判文书网。
- **合规红线**：先备案后上线；不称"律师/包赢"；刑事辩护 100% 转人工；平台与律所关系完全独立。
- **学生团队路径**：第一年现金支出可压至千元级，以大创经费、创新创业大赛奖金和政府扶持"以赛养创"，暂不融资、暂不注册公司。
- **未来规划**：在校验证 → 毕业公司化 → 成长扩张 → 平台生态四阶段，保留 C 端 / B 端 / G 端 / 律师端 / 并购 / 横向扩展 / 涉外七条发展分叉。
