# legal-ai-agent-research 仓库说明文档

> 一句话简介：普惠法律智能体 · 架构调研与落地蓝图（学生团队近零成本创业方案）

## 一、项目概述与定位

`legal-ai-agent-research` 是一份面向「**普惠法律智能体**」的系统性架构调研与落地蓝图。它回答一个具体创业命题：面对"现代人法律意识淡薄、法律服务门槛高（律师咨询常 200–800 元/小时起，小额维权成本接近标的）"的痛点，能否、以及如何由一个学生团队，以近零成本做一个「AI 普惠法律入口 + 真人律师合规变现」的产品。

仓库本身**不含可运行代码**，是一套"调研材料 + 决策报告"的文档型仓库：

- **问题背景**：2024 年全国法院受理案件约 4601.8 万件、消费投诉超 1862 万件，高频集中在借贷、买卖、离婚、交通事故、劳动争议等场景；
- **目标产出**：一份可直接指导产品开发、参赛申报与融资的完整决策报告；
- **总打法**：AI 做免费普惠入口 + 真人律师做合规变现；不自研基座模型，胜负手在法律数据深度、场景闭环与合规信任；
- **学生路径**：第一年现金支出压到千元级，靠大创经费、创新创业大赛奖金与政府扶持"以赛养创"，暂不融资、暂不注册公司。

## 三、研究框架与八份调研材料脉络

八份材料按"市场 → 竞品 → 技术 → 数据 → 合规 → 产品商业 → 学生资源"的决策逻辑层层推进，每份均以「核心发现（摘要）」开篇、以「参考来源」收尾：

1. **01 市场与政策环境**：C 端/B 端法律需求盘点（纠纷盘子、高频场景案件量、用户分层画像）、法律科技市场规模与融资、国家与公共法律服务政策驱动，落到目标用户四类分层。
2. **02 国内竞品**：逐一分析约 15 类玩家——百度法行宝、阿里通义法睿、科大讯飞星火晓法、北大法宝、威科先行、无讼、华宇万象、幂律智能、法狗狗、iCourt AlphaGPT、秘塔 MetaLaw、法天使、老牌法律互联网平台（律图/找法网/赢了网）、大厂布局（字节/腾讯/华为）、DeepSeek 系新兴力量，末附功能矩阵对比表。
3. **03 国外竞品**：2024–2026 年约 16 个海外产品——Harvey、Casetext/CoCounsel、Lexis+ AI/Protégé、Westlaw、DoNotPay（C 端"机器人律师"反面教材）、LawGeex（衰落警示）、Robin AI、Spellbook、EvenUp、Hebbia、Legora、Luminance、Kira、Eigen、SpotDraft，以及 Microsoft/Google/OpenAI 大厂动向，末附"可借鉴 vs 不可照搬"总结。
4. **04 技术架构**：六层架构总览与组件清单；法律垂直大模型三条路线对比（推荐开源底座后训练组合、分三阶段演进）；完整 RAG 方案（数据摄入、分块、Embedding/Rerank、查询改写多跳、引用溯源控幻觉、GraphRAG/Agentic RAG）；MCP 化工具集与 Function Calling/ReAct 工程；多 Agent 拓扑「1 前台 + 4 专业 + 1 审核」；把 IRAC、邹碧华"要件审判九步法"显式映射为工作流节点；多模态方案；推荐技术栈组合表。
5. **05 数据体系**：法律数据源全景（官方免费库/商业授权/开源数据集三层）、获取方式与爬虫法律风险、版权与个人信息红线、清洗脱敏流水线与法律知识图谱实体关系、合成数据与专家标注、事件驱动更新、存储分工与 Hybrid RAG 检索流水线。
6. **06 监管合规**：先给"必须做/禁止做"红线清单；生成式 AI 三部规章与备案要求；"从事法律服务"的资质边界与 AI 公司如何规避违规、与律所合作的合规架构；输出责任划分（引最高法意见）；免责声明必备条款；数据安全与个保法；广告宣传合规；敏感场景处理表；UGC 平台责任；DoNotPay 案警示。
7. **07 产品与商业路线**：C 端/B 端功能矩阵；RICE + MoSCoW 功能优先级与 3 个月 MVP 清单；交互形态选择；商业模式对比；基于实际数据的定价参考；获客渠道；分阶段落地路线图与甘特图；团队配置（MVP 4–6 人 → 成长期 15–20 人）；第一年成本粗估；冷启动、数据飞轮与竞争壁垒。
8. **08 学生资源**：大学生创新创业大赛赛历与奖金扶持表；逐项核实的免费云算力与免费 token 清单、自托管技术栈；学校资源与大创经费；河南/郑州政府补贴与贷款；本地孵化器；学生创业特殊合规（主体注册、学籍休学、知识产权归属、大模型备案）；融资阶梯参考；第一年现金支出测算；未来 12 个月比赛/项目日历。

## 五、核心结论（README 摘要）

- **技术路线**：开源底座法律后训练 + 强工程化 RAG + LangGraph 多 Agent（前台接待 / 法律分析 / 类案检索 / 文书起草 / 合同审查 / 合规审核）；
- **数据策略**：免费官方库（国家法律法规数据库、人民法院案例库等）+ 商业授权 + 开源数据三层组合，不依赖批量爬取裁判文书网；
- **合规红线**：先备案后上线；不称"律师/包赢"；刑事辩护 100% 转人工；平台与律所关系完全独立；
- **未来规划**：在校验证 → 毕业公司化 → 成长扩张 → 平台生态四阶段，保留 C/B/G 端、律师端、并购、横向扩展、涉外七条发展分叉。

## 六、项目特点小结

- 这是一份"调研即产品"的落地蓝图：不是泛泛行业综述，而是围绕一个学生创业命题，把市场、竞品、技术、数据、合规、商业、资源七条线全部收敛到"能不能做、怎么做、花多少钱"的决策上；
- 方法论扎实：功能优先级用 RICE+MoSCoW、技术选型做多路线对比、合规列红线清单、成本给到具体测算；
- 定位务实克制：明确"AI 做普惠入口、真人律师做合规变现"，强调合规边界与数据来源合法性，报告本身附免责声明、不构成法律意见。
