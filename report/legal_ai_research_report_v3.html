一、执行摘要（学生团队版总判断）

本报告在 V1《8人团队、首年200万预算》调研稿基础上，按"在校大学生兼职团队、资金极有限、近零成本启动"这一新约束重写。市场、竞品、技术、数据、合规中仍成立的判断予以保留（见第二至八章），但所有"推荐结论、投入、团队、第一步"全部按学生处境推倒重来：不找天使融300万、不租办公室、不养全职团队、不现在就注册公司、不自建大模型备案，先用一学期把东西做出来、把真实用户跑出来，再决定要不要All in。

一句话总判断 法律科技正从"信息检索/法律电商"切换到"大模型+法律Agent"阶段：2024年中国AI法律工具融资23起、合计48.6亿元[22]，全球法律AI市场2025年约45.9亿美元、年增约21.8%[14]。但C端已被百度法行宝以"完全免费"横扫（服务用户超7000万）[CN-4]，合同审查B端已成红海。对一个没钱、没时间（还要上课）的学生团队，正确姿势不是正面拼流量、拼融资，而是"近零成本验证 + 以赛养创 + 先做深一个校园/民生细分场景"：用已备案大模型的免费额度、免费云资源、Dify社区版/Coze免费版把MVP跑起来，用大创项目、互联网+大赛、挑战杯拿奖金和背书，用法学院实践基地/法律援助社团解决"法律质量谁来兜底"，毕业节点再注册公司、再谈融资。
推荐技术路线（学生起步版，工程化但不烧钱） 不自研基座、不自部署大模型、不现在做自有大模型备案。起步直接调用已备案商用API的免费额度（硅基流动免费模型 / DeepSeek / 通义千问·百炼 / 智谱GLM的学生或新用户免费额度），用免费云服务器/Serverless + 免费对象存储，编排层用 Dify 社区版（可自托管、数据自有）或 Coze 免费版（出活快）先搭出可用产品。法律RAG的工程规范（双路检索、引用回链、废止法条校验）从第一天就按第四章标准做，但实现上先用开源embedding+免费向量库。LangGraph 这类可迁移的代码化编排框架作为进阶方向，不把核心流程锁死在某个可视化拖拽平台里——这样毕业过渡到公司时不用推倒重来。
推荐MVP范围（先打校园身边人） 第一个学期不要上来就做"万能法律AI"，先打透学生和普通人最痛、又最容易在身边找到真实用户的场景：兼职/实习劳动纠纷（欠薪、N+1、工伤）、租房押金纠纷、校园贷/培训贷、消费维权（网购、美团外卖、预付卡跑路）、简单借条/劳动仲裁文书。交付"智能多轮咨询 + 法条大白话解读 + 赔偿/费用估算器 + 法律文书按次生成"四个P0功能，先跑在微信小程序/公众号或H5上。这些场景需求刚性、用户就在身边（同学、学长学姐、校园周边商户），不用花钱投流就能拿到第一批真实反馈。
推荐合规架构（学生最轻路径） 在学生期、未注册公司阶段，不碰需要重资质的业务：只做"法律知识科普 + 通用文书模板 + AI辅助分析（仅供参考）"，刑事辩护、会见、取保、出庭100%不碰，一律引导到学校法律援助中心、12348公共法律服务热线、合作律所。技术上只调用已备案模型API、并在产品页公示所用模型名称与备案号，由此免去"自部署大模型需亲自做国家生成式AI备案"的重负担；面向公众提供前按地方网信办要求做应用登记。法律内容的准确性把关，由团队内部法律专业成员 + 其法学院导师与实践基地网络完成抽检（导师通常不付顾问费），不需要现在外聘付费律师。
学生期合规红线（生死线，缺一不可） ①产品始终自称"法律AI工具/普法助手"，禁用"律师/法律顾问/包赢/100%胜诉/不赢不收费"话术；②每次AI输出持续标注"AI工具、不构成法律意见、不替代律师"；③刑事、未成年、群体事件、国家秘密、帮人毁灭/伪造证据等场景100%熔断、转人工或引导12348；④只用境内已备案模型API、用户咨询数据默认不用于训练、不出境；⑤学生期不代收律师费、不与律所做案源分成（传统"挂靠/联营"已被郑州等地穿透认定封堵[C-18]）；⑥注意知识产权归属——避免因使用学校实验室资源、导师课题经费导致成果被学校主张（详见第九章学生特殊合规）。DoNotPay因宣称"机器人律师可替代真人"被美国FTC罚款19.3万美元[F-13]，是必须研究的反面教材。

第一年现金支出：目标压到 0–10 万元，其中大部分可以是 0 元。学生期最大的"成本"不是钱，是时间和学业。现金主要花在：服务器/API超出免费额度后的小额账单（每月几十到几百元）、小程序认证（300元/年）、比赛报名费与差旅、必要的软件/域名。钱从哪来：先用比赛奖金（互联网+、挑战杯、大创、各行业赛，校级→省级→国家级单个数百到数万元）→ 大学生创新创业训练计划经费（国家级/省级立项数千到数万元）→ 郑州市/高新区大学生创业补贴与孵化器免费工位 → 毕业前后再谈种子/天使。在没拿到第一笔比赛奖金和真实付费数据之前，不要融资、不要注册公司、不要签任何长期租约。

第一步行动（本周即启动） 拉上法学院实践基地/法律援助社团，列一张"同学身边真实法律问题清单"（先访谈20个同学/学长）；注册公众号和抖音/小红书号开始"普法内容先行"；镜像国家法律法规数据库与人民法院案例库搭最小知识库；用DeepSeek/通义免费API跑通第一个"兼职欠薪→能赔多少→仲裁申请书生成"闭环。详见第十一章"未来一学期90天按周清单"。

2.7 需求测算与机会判断

把上述宏观数据折算成可操作的市场假设：以最高频的劳动争议为例，全国年收案约61.4万件，但若把"被辞退想知道能赔多少""没签合同能不能要双倍工资"这类有纠纷但尚未起诉的潜在咨询者计入，实际有诉求的人群是已立案案件的数十倍。这与公共法律服务平台五年累计1.7亿次咨询、司法所年均2950万人次解答的数据相互印证——真正的市场是"已立案案件量"背后那个未被满足的长尾。对一个MVP产品而言，只要在抖音"离职N+1怎么算"这类精准长尾流量中拿到千分之几的转化，就能在数月内积累数万真实咨询用户。

付费意愿的结构性错配是本项目最重要的商业洞察：C端对"咨询"本身极度价格敏感，但对"直接产出一份能用的文书、直接算出我能拿多少钱"这类确定性结果的支付意愿显著更高。这解释了为什么行业里跑通的是"文书按次付费"（19.9–49.9元，用户感知是省下了几百上千元律师费）而非"包月咨询会员"。同理，律师导流佣金之所以是第一年收入主力，是因为案件代理费（动辄5000–5万元）的客单价足够高，即使只抽成15–20%、转化率不高，绝对收入也远高于C端会员费。

政策端的顺风与红线必须同时看清：一方面，"法仪大模型"发布、六五改革纲要要求强化大模型辅助办案、公共法律服务三平台融合、法律援助法取消事项限制，都在为AI+法治打开G端采购与C端普惠空间；另一方面，最高法2026年9月专门就AI纠纷审理出台意见、惩治利用AI虚假诉讼、规范AI生成内容证据效力[M-18]，意味着监管已经从"鼓励发展"进入"规范发展"阶段。对创业团队而言，这恰恰是好事——它把"靠噱头、靠套壳、靠夸大宣传"的低质竞争者挡在门外，抬高了"可溯源、可解释、合规"产品的信任壁垒。

三、竞品研究

3.1 国内竞争格局：三层梯队、两条主线

国内法律AI已形成稳定梯队：第一梯队为大厂基座派（百度法行宝、阿里通义法睿、讯飞星火法律）与专业数据派（北大法宝、威科先行）；第二梯队为垂直深耕派（iCourt AlphaGPT、幂律智能、法狗狗、法天使、秘塔MetaLaw）；第三梯队为老牌法律互联网平台（律图、找法网、无讼）的AI补课与各地公共法律服务平台对DeepSeek的批量接入[CN-1]。

两个关键行业共识 ①"通用大模型+法律垂域精调+RAG+知识图谱"已成事实标准，几乎无玩家再从零训练法律基座；②数据壁垒是最硬的护城河——北大法宝坐拥596万+法规、1.88亿+案例、4750万+行政执法数据，通义法睿用1.6亿份司法文书训练[CN-12]。谁掌握结构化、可溯源、时效新的法条与案例库，谁就能压制通用大模型的幻觉。

3.3 市场空白与机会点

  1. 空白一：面向中小律所/独立律师的"端到端办案Agent"仍不完美。现有产品多为单点工具（检索、审合同、写文书），能真正"从接案—类案检索—证据梳理—法律关系图谱—文书生成—开庭准备"全流程自主串联的Agent极少。
  2. 空白二：可溯源、可解释、带责任界定的"专业级Agent"。面向律师/企业法务、每条结论一键溯源到法条/判例原文、并记录律师审核留痕的合规级Agent，是高价值缺口。
  3. 空白三：企业法务"合同全生命周期+合规监控"闭环仍未被打通；从起草—审查—签署—履约提醒—纠纷预警—案件管理一体化Agent稀缺。
  4. 对中国团队的现实窗口：C端被法行宝免费横扫，单独付费C端无生存空间；合同审查B端已成红海；但"AI做免费流量入口 + 真人律师做合规变现出口"的普惠闭环，以及嵌入微信/飞书/钉钉的中小微工作流，仍有机会。

3.4 国内外格局交叉判断

把国内与国外两张矩阵放在一起对照，能得出几个对决策至关重要的结论。第一，全球技术路线已经收敛：无论国内的通义法睿、iCourt，还是国外的Harvey、Spellbook、Legora，都不再从零训练基座，而是"通用/开源底座 + 法律领域后训练 + RAG引用回链 + 模型路由"。这意味着创业团队在技术选型上没有路线之争，真正的分野在数据与工作流。第二，数据护城河的逻辑中外一致：国外靠Westlaw、LexisNexis百年判例库，国内靠北大法宝、威科的结构化标注；没有合规、权威、可溯源的法律语料，再强的模型也会幻觉出假案例。对中国创业团队而言，问题在于裁判文书公开政策已收紧、不存在Westlaw式的可自由使用的百年库，因此必须走"官方案例库 + 商业授权 + 自建脱敏语料 + 专家标注"的组合，而非幻想爬取全量文书。

第三，产品形态上"嵌入既有工作流"是中外共同的胜负手：Spellbook活在Word里、Luminance做Word插件、Copilot绑Office；国内则应嵌入微信（C端）、飞书/钉钉/企微（B端）、Word/WPS（律师文书）。独立大而全的网页端产品，无论中外，转化率都显著更低。第四，商业化上"B端被验证、C端噱头被证伪"：国外所有跑出来的公司都服务律所/法务，DoNotPay因C端"机器人律师"被FTC处罚；国内C端已被法行宝免费教育。这共同指向一个清醒定位——用免费C端做流量与品牌，但把收入押在律师导流与B端工具上，绝不在C端做"替你打官司"的重承诺。

最后需要正视不可照搬之处：Harvey/Legora那种"套壳基础模型 + 天价估值"建立在美元风投与Am Law顶级律所付费土壤之上，中国市场缺少这种土壤；美国按席位300–600美元/月的高定价也无法直接复制。中国团队的现实路径是印度SpotDraft式的"低成本工程 + 垂直场景做深"，甚至未来用中文法律能力出海东南亚普通法/涉外合同市场——这是比死守国内高合规市场更可能跑通的补充选项。

4.5 法律推理工程化：IRAC × 要件审判九步法

不要指望模型自己"像律师一样思考"，而要把IRAC（Issue争议焦点→Rule法律依据→Application涵摄→Conclusion结论）拆成LangGraph显式节点，每步强制产出结构化JSON，审核节点校验"结论是否被Rule+Application支撑"。

4.9 成本控制与模型路由经济学

法律对话看似复杂，实则绝大多数请求是"低难度高频"的——用户口语化咨询、文书模板填充、法条解释，完全可以用便宜的快模型（Qwen3-32B或DeepSeek-V3.2类）处理；只有真正需要法律推理的"要件拆解、类案比对"环节，才值得调用贵的推理模型（DeepSeek-R1类，长CoT，慢且贵）。这种按任务路由正是Harvey"单次查询调用数十次小模型"的省钱逻辑：不要把所有请求都打给最贵模型。配合DeepSeek-V4-Flash输入约1元/百万tokens、输出约4元/百万tokens的极低价格[B-3]，单用户日均咨询成本可控制在0.1–0.3元，文书生成的边际成本仅约0.05–0.2元/份——这是文书能定价19.9–49.9元仍保持95%毛利的根本原因。

工程上还有两个必须从第一天就建立的习惯。其一是评测（eval）文化：法律AI不能靠"感觉变好了"迭代，必须用Langfuse+RAGAS持续度量三个指标——引用准确率（生成的法条/案号是否真实且现行有效）、忠实度（结论是否被检索到的依据支撑）、拒答率（该拒答时是否拒答）。每次模型或prompt改动都跑回归集，防止"改好一个场景、改坏三个场景"。其二是确定性优先于模型智能：凡是能算的（诉讼费、利息、违约金、N+1）一律走代码计算器，绝不让LLM算；凡是能模板化的（标准起诉状）一律走模板引擎让LLM只填空；只有真正开放的语义理解才交给模型。这种"把不确定性关进笼子"的工程纪律，是法律AI区别于普通聊天机器人的核心。

学生团队的成本观：在校期用户量小（几百到几千），API免费额度基本够用，真实现金模型账单大概率每月0–几十元；真正要防的是"为了看起来专业而过早自部署、过早买GPU"——那是毕业公司化、有了收入和融资之后才该做的事。但"按任务路由、能算的不让LLM算"这些习惯现在就要养成，否则用户量一上来账单会失控。

5.5 数据合规的特别警示

数据是法律AI的护城河，也是最容易踩雷的地方。两条红线必须反复强调。其一，已公开的个人信息不等于可以随便商用：最高法入库参考案例"麦某波案"明确，把已公开裁判文书中的当事人信息经筛选、加工、评价后做成商业数据产品，已超出"合理范围"，构成侵犯个人信息权益[D-14]。即使官方文书已隐名，结合工商、执行、庭审数据仍可能反向识别到自然人，合规上即视为"可识别"。因此入库前必须做NER脱敏（姓名保留"张某某"、隐去身份证/手机号/住址/账号），禁止"以人搜案""以企业搜全部涉诉"的人肉功能，不做当事人信用评分或催收线索产品，并留存来源与脱敏日志至少3年。

其二，著作权上"法条本身无版权，但数据库编排受保护"：法条原文、裁判要旨可合理引用，但商业库（北大法宝、威科）的结构化标注、法条关联、标签体系受汇编作品著作权与反不正当竞争法保护，直接镜像再分发等于高危。这也是为什么商业采购合同必须单独谈判"数据可用于AI训练/内嵌检索"的明确授权——多数标准订阅默认禁止把原始文书入库训练大模型。综合下来，MVP阶段最稳的数据组合是：国家法律法规数据库（免费、无版权争议）+ 人民法院案例库（官方鼓励类案检索）+ 企查查/天眼查授权API（合规、按量付费）+ 开源SFT数据集（DISC-Law-SFT等做冷启动），把钱花在权威小数据与专家标注上，而非爬一个随时可能被封、且有刑事风险的裁判文书网。

7.5 合规红线清单

【必须做】合规底线，缺一不可 1. 完成生成式AI+算法"双备案"后才能上线；2. 每次AI输出持续标注"AI工具、不构成法律意见、不替代律师"；3. 建投诉举报、内容安全、违法输入拦截机制；4. 刑事辩护/会见/取保/出庭100%转持证律师；5. 敏感个人信息单独同意、数据最小化、加密存储、限期删除；6. 用境内已备案模型、境内存储，不直接调境外API处理中国用户数据；7. 用户协议设责任限制+风险提示并保留确认记录；8. 重大财产/诉讼时效/刑事风险主动触发转律师通道。
【禁止做】触碰即红线 1. 禁用"律师/法律顾问/包赢/100%胜诉/不赢不收费"话术；2. 禁止AI生成代理词/辩护词无律师审核即交法院，禁止代为出庭/立案/会见；3. 禁止与律所案源分成、挂靠资质、代持合伙、咨询公司实控律所；4. 禁止引导毁灭/伪造证据、串供；5. 禁止处理<14岁未成年人咨询无监护人同意；6. 禁止在AI文书上标注"AI律师出具"或冒充律师签章、伪造裁判文书；7. 禁止将用户咨询数据用于训练而不单独同意、禁止出境/出售。
输出责任划分（最高法2026意见） 错误法律建议致用户损失原则上按过错责任归责——平台若已尽风险提示、人工复核、及时更正义务可显著减责；无实物载体的法律AI对话服务排除在产品责任无过错责任之外（有利）；AI自动生成侵权内容参照"避风港规则"，经通知后须及时止损。但免责声明不是万能通行证：若明知AI存在系统性错误仍放任输出，仍可能被认定过错[C-7][C-23]。建议要求合作律所投律师执业责任险，自身投保网络安全责任险+科技产品E&O保险。

7.6 免责声明与话术纪律

合规不是挂一条用户协议就完事，而是要在产品的每一个触点上持续、显著地传递"AI工具、不替代律师"的信号。具体而言：每次AI输出法律相关内容时，底部都应重复提示，而非只在用户协议里藏一条；涉及诉讼时效、重大财产权益、刑事风险时主动弹出"建议咨询持证律师"并给出转人工入口；所有AI生成内容标注"AI生成"，并提示用户提交法院时须自行核实并披露AI使用情况——最高法2026意见明确，诉讼参与人对AI生成的诉讼文书、案例检索报告负有核实说明义务，不得以"AI幻觉"免责。

话术纪律上，DoNotPay案给出了最直接的教训：FTC处罚的核心不是它做了AI法律咨询，而是它在未做任何准确性测试、未聘请律师验证的情况下，对外宣称"机器人律师可替代真人"[F-13]。对应的正确姿势是：永远自称"法律AI工具/助手"，绝不称"律师/法律顾问"；广告中突出工具属性与免费普法价值，绝不作结果承诺；对L3个性化输出坚持有持证律师抽样审核、建立可对外说明的质量评估机制——这既是合规要求，也是把"信任"做成产品壁垒的方式。2025–2026年郑州、泉州等地已专门出台规定，穿透认定法律咨询公司实质控制律所、案源分成等合作，传统"挂靠/联营"模式已被明确封堵，本项目必须从第一天就采用纯中立技术平台模式。

9.9 数据飞轮与壁垒（学生版）

数据飞轮：用户提问→AI生成回答/文书→用户反馈（有用/没用/纠错）→差评对话进法律专业成员+导师审核队列→修正后入标注集→优化prompt与知识库→更好回答→更多用户。每次对话结束弹"这个回答帮到你了吗"，积累的"真实校园/民生咨询 + 导师验证答案"是竞品无法短期复制的核心资产。

关键认知：模型本身不构成壁垒——DeepSeek/Qwen人人能用、免费额度人人能领。学生团队真正的壁垒是校园/民生垂直场景的规则精度 + 导师与法援网络 + "真实问题+验证答案"的数据飞轮 + 比赛打出的品牌背书。这四者都靠时间和免费积累，恰恰是学生最不缺、大公司最懒得做的。

十、未来规划与长期演进

本章是 V2 学生版新增的核心章节。学生创业最大的风险不是"做不出来"，而是毕业即散伙、技术做了一堆却不能迁移、拿到第一笔钱时方向已经跑偏。因此本章回答六个问题：四年后这家公司长什么样、现在的简版技术怎么不推倒重来、什么数据信号出现时该走哪条路、零成本阶段该攒下什么资产、钱分几步拿、团队怎么随毕业成长。

10.3 发展分叉与决策信号

学生团队最容易犯的错，是一上来就把自己定义成"做C端法律AI平台"。实际上做满一年后，真实数据会告诉你该走哪条路。下表列出六条可能的分叉路，以及出现什么数据信号时就该果断转向那条路，而不是凭想象选。

分叉路线出现这些数据信号时选它说明
A. C端普惠流量平台注册用户百万级、月活高、但付费率低、主要靠广告/导流变现靠规模和品牌，需要持续获客投入，学生期可先攒流量，但难独立盈利
B. 合同法务SaaS（小微/企业）付费客户中B端占比过半、客单价数千元/年、续费意愿强、销售可复制收入稳定、ARR可预期，是资本最认可的路径；从合同审查/用工合规切入
C. G端智慧司法/法援采购拿到法院/司法局/法援中心的试点或中标记录、有政府背书案例单子大但周期长、要资质和行业关系，通常毕业公司化后、有行业合伙人再进
D. 律师端办案工具用户中执业律师占比高、留存好、愿按席位付费客单高、决策快，但要钻进律师真实工作流（Word/类案/阅卷）
E. 被并购/成为大厂生态伙伴做到了特定场景深度或区域密度，大厂/律所集团需要这块能力补位不必硬撑独立IPO，被通义/百度/头部律所集团收购也是成功退出；保留产品独立性

11.2 成功关键与失败模式（学生版）

学生团队跑通这个项目，同样要同时答对三道题，但尺度和全职公司完全不同。第一是需求题：不做"万能法律AI"，死死咬住同学身边的兼职欠薪、租房押金、校园贷、消费维权这几个最痛、最容易找到真实用户的场景，把规则和文书做到极致。第二是信任题：每条结论可溯源、每次输出带免责、敏感场景坚决转人工、文书有人工复核兜底——宁可少回答，不可乱回答。第三是节奏题：认清在校期的目标是"验证+攒数据+拿比赛背书"，不是"赚多少钱"，把不花钱的免费额度、导师网络、大创和比赛用足。

学生团队特有的失败模式也要警惕：一是技术理想化——沉迷自部署、微调、自研模型，烧钱又分散精力，结果产品闭环没跑顺；二是过早公司化/过早融资——还没有真实数据就注册公司、谈天使，既过早稀释又背上运营成本；三是不留后手——代码只在一个人电脑里、成果用了学校资源、没签股权协议，一毕业就散伙甚至被学校主张知识产权。本报告给出的近零成本路径、知识产权隔离协议与毕业交接安排，正是为了同时规避这三类失败。

最后要有清醒预期：模型本身不构成壁垒，免费额度人人能领，真正的壁垒是校园/民生垂直场景的规则精度、导师与法援网络、以及"真实问题+人工验证答案"的数据飞轮。这些都靠时间和免费积累，恰恰是学生最不缺、大公司最懒得做的事——用一学期跑通闭环、用在校期攒下别人抄不走的数据，就是学生团队最大的机会窗口。
