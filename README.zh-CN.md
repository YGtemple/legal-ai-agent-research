# legal-ai-agent-research

一个普惠法律智能体的调研与落地蓝图——学生团队近零成本方案。

<sub>HTML · research/ 与 report/</sub>

---

## 前提

法律咨询很贵，而且分布不均。学生团队养不起律所的工具，所以这份研究问的是一个更窄的问题：**接近零成本能做出什么，而且仍然真正有用？**

这个答案决定了后面的一切。它排除了微调模型、专用基础设施，以及任何需要牌照才能运营的东西。剩下的，是一个跑在公开法规与程序之上的窄领域智能体，并且明确划出它会回答什么、不会回答什么。

## 结构

```
research/    原始调研——来源、已有做法、法律约束
report/      由它得出的结论
```

原始发现和结论分开存放。结论可以拿回产生它的证据里复核，而证据不会为了迁就后来的论点被改写。

## 报告覆盖什么

- 哪些法律问题能从公开来源回答，哪些不能
- 成本底线实际在哪（托管、模型调用、数据）
- 合规边界——这类工具可以声称做什么、不可以声称做什么
- 给小团队的实施顺序

## 范围

这是研究与蓝图，不是已部署的服务。法律结论受司法辖区限制，通用工具盖不住这一点，报告也是这么写的，没有含糊过去。
